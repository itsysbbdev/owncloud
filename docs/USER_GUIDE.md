# OwnCloud Felhasználói Útmutató (User Guide)

Üdvözöljük az ownCloud magántulajdonú, felhőalapú fájlmegosztó és együttműködési rendszerében!

## Elérhetőség
A rendszer az alábbi címen érhető el érvényes SSL (HTTPS) védelemmel:
* **URL:** [https://oc.botzheim.eu](https://oc.botzheim.eu)

## Bejelentkezési adatok
A rendszer első indulásakor az alábbi alapértelmezett adminisztrátori fiók jön létre:
* **Felhasználónév:** `ocadmin`
* **Jelszó:** (A telepítés során megadott biztonságos jelszó / az Azure Key Vaultban vagy a deployment logokban rögzített jelszó)

> **Biztonsági figyelmeztetés:** Első belépés után javasolt a jelszó megváltoztatása a jobb felső sarokban található profil menüben, valamint új felhasználók létrehozása a csapattagok számára.

## Főbb Funkciók
* **Fájlok feltöltése és szinkronizációja:** Dokumentumok, képek és mappák tárolása, megosztása jelszóval vagy lejárati idővel.
* **Kliensalkalmazások:** Az ownCloud hivatalos kliensei letölthetők Windows, macOS, Linux, valamint iOS és Android rendszerekre is a hivatalos [ownCloud Download](https://owncloud.com/download/) oldalról. A szerver URL-jeként add meg a `https://oc.botzheim.eu` címet.
